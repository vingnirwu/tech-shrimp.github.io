标签学习1

<!DOCTYPE html>
文档类型声明标签 --并非是html标签

<html lang="en">
lang来定义文档显示的语言
1.en是英文
2.zh-CN是中文
但其实en与zh-CN的网页均可显示中英文
仅对浏览器起提示作用

<head>
    <meta charset="UTF-8">
    <meta>标签下的charset用来定义HTML使用哪种字符的编码
    不写会出现乱码

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>

<body>
    标题标签
    <h1></h1>
    <h2></h2>
    <h3></h3>
    <h4></h4>
    <h5></h5>
    <h6></h6>
    h1-h6是标题标签，加粗显示，级别依次

    段落标签
    <p></p>
    用段落标签把文字分段，分别储存段落

    换行标签
    <br />
    换行标签，强制换行，空行比段落小
    单标签，无需结束标签

    文本格式化标签
    为文字设置粗体，斜体，下划线等效果
    <strong></strong>或<b></b>————加粗
    <em></em>或<i></i>————倾斜
    <del></del>或<s></s>————删除线
    <ins></ins>或<u></u>————下划线

    无语义标签
    <div></div>
    <span></span>
    div标签一个*独占一行*
    span一行可以放多个
    网页布局中很重要

    图像标签*
    <img src="图像URL" alt="替换文本" title="提示文本" width="宽度" height="高度" border="边框" />
    图像标签为单标签，src后为所插入图像文件的路径和文件名，/用来表示这个为单标签
    一般图像文件需存储入同文件夹
    alt为替换文本，在文件显示不出来时显示
    title为提示文本，在鼠标悬浮时显示文字
    width为图像设置宽度
    height为图像设置宽度
    border为图像设置边框粗细

    注意：
    1.图像标签可以有多个属性，必须在标志名后面
    2.属性不分先后顺序，以空格分开
    3.key="value"格式

    超链接标签*
    <a href="跳转目标" target="目标窗口弹出方式">链接文本</a>
    herf为链接目标的url地址，为必须属性
    target用于在指定打开方式，_self为默认值以当前窗口打开，_blank在新窗口打开
    链接分类：1.外部链接
    <a href="http://www.qq.com">腾讯</a>
    http://+外部网站
    2.内部链接
    <a href="创建页面.html"></a>
    无需http://
    3.空连接
    <a href="#"></a>
    用#代替
    4.下载链接
    <a href="img.zip">下载</a>
    herf里为文件
    5.网页元素链接
    <a href=""><img src="image/immg.jpg"></a>
    用网络元素替代文本被a标签包含
    6.锚点链接
    <a href="#名字"></a>
    <img src="image/immg.jpg" id="名字">
    定位到页面中某个位置
    herf为#+名字，名字在原本的目标标签中加入id属性
    可用于返回顶部等用处

</body>

</html>
